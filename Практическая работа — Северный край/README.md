# Атлас северной тишины

Многостраничный адаптивный сайт «Интерактивная карта мифов и легенд Северного края».

## Состав проекта
- `index.html` — главная страница с интерактивной картой.
- `legends.html` — каталог легенд.
- `about.html` — концепция и сведения о проекте.
- `style.css` — палитра, типографика, адаптивная сетка и CSS-орнаменты.
- `script.js` — фильтрация, выбор меток карты и мобильное меню.
- `mockup-desktop.svg`, `mockup-mobile.svg` — схематичные эталоны макета для 1280 и 375 px.

## Запуск
Откройте `index.html` в браузере. Для локального сервера можно выполнить:
```bash
python -m http.server 8000
```
Затем перейдите на http://localhost:8000/Практическая%20работа%20—%20Северный%20край/.

## Концепция
Пять ключевых слов: **Север, память, туман, путь, сияние**.

Интерактивный атлас собирает авторские мифологические истории северного края в единое пространство, создавая настроение тихого исследования, тайны и уважения к памяти места.

## Дизайн-система
- Палитра: ночной сине-зелёный, светлый туман, приглушённый бирюзовый и янтарный акцент.
- Заголовки: Playfair Display; основной текст: PT Sans (системные запасные шрифты).
- CSS: полосатый разделитель `.divider-stripes`, точечная подложка `.bg-dots`, круг-мандала `.hero-circle`.
- SVG-символ: авторский северный олень из простых геометрических фигур.

Все легенды на сайте — художественные авторские интерпретации для учебного проекта, а не документальные этнографические источники. Визуальные образы созданы средствами CSS и SVG; картины с выставки не копируются.

## Структура сайта
1. Главная — интерактивная карта, избранные истории, направления исследования.
2. Легенды — каталог историй с фильтрами по миру.
3. О проекте — идея, визуальный язык и условные обозначения.

## Проверка адаптивности
Основные контрольные ширины: 375 px, 768 px и 1280 px.
